# One Word From Grandma

Entry for the make.fun competition "One Word From Grandma" (u-0xkianno-one-word-from-grandma-f04bed16): exactly one word — the word grandma would text about AI.

The entry word is **Robit**: grandma's own typo for "robot". It is the single word she would actually send — warm, a little baffled, funny with no caption needed, and unmistakably about the machines. `main.ts` writes that one word to `/output/entry.txt` deterministically and exits 0.
